# Changelog

## v0.3

- Added a Settings window accessible from the tray menu.
- Added independent enable/disable controls for the three Genshin macros.
- Added configurable double-tap and repeat timing intervals.
- Added persistent settings via Qt QSettings.
- Added a startup preference for the initial macro enabled state.
- Added Restore defaults and interval-bound validation.
- Preserved v0.2's virtual mouse identity behavior and Genshin-only focus detection.
